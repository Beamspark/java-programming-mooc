## 🧠 Mapa de Competencias Técnicas

- **Fundamentos y Control de Flujo:** Tipado estático, conversión explícita (*casting*), manejo de entrada/salida estándar (`Scanner`), lógica booleana compuesta y bifurcación condicional.
- **Gestión de Memoria y Ámbito:** Diferenciación entre tipos primitivos (asignación directa en *stack*) y tipos por referencia (objetos en *heap*), así como ciclo de vida y visibilidad de variables (*scope*).
- **Iteración y Modularidad *(En curso)*:** Diseño de bucles condicionales y definidos, patrones de acumulación y descomposición funcional mediante métodos.
