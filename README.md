## 💡 Conceptos Clave Asimilados

### Tipos de datos y memoria
* **Tipos primitivos vs. referencia:** `int`, `double` y `boolean` almacenan el valor directamente en la pila (*stack*), mientras que `String` y los objetos almacenan referencias a memoria (*heap*).
* **Ámbito de variables (*Scope*):** Las variables declaradas dentro de un bloque condicional o bucle dejan de existir fuera de sus llaves `{}`.

### Estructuras de control
* **Operadores lógicos:** Uso de `&&` (AND), `||` (OR) y `!` (NOT), prestando atención a la evaluación en cortocircuito.
* **Control de flujo:** Diferencia entre bucles condicionales con centinela (`while`) y bucles con contador definido.
