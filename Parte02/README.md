# Parte 02: Estructuras Repetitivas y Métodos

Notas y ejercicios correspondientes al segundo bloque de Java Programming I (Universidad de Helsinki): patrones de cálculo, bucles (`while` y `for`) y descomposición modular mediante métodos.

---

## 📌 Conceptos Clave Asimilados

1. **Patrón de resolución de problemas (Entrada → Proceso → Salida):**
   * Estructuración sistemática de cualquier algoritmo en tres fases diferenciadas: captura y conversión de datos de entrada (`Scanner`), transformación o cálculo mediante variables auxiliares, y presentación del resultado por consola.

2. **Funciones matemáticas estándar (`java.lang.Math`):**
   * Java incluye la clase `Math` de forma nativa (sin necesidad de `import`) para operaciones matemáticas habituales como raíces cuadradas (`Math.sqrt(valor)`), que devuelve siempre un resultado de tipo `double`, o valores absolutos (`Math.abs(valor)`).
